# Bloom Parser

A utility to extract Mindful Session data from an Apple Health export and output a CSV file for import by [Bloom], a Discord bot that offers meditation tracking functionality in the [Meditation Mind] server.

## Usage

1. Export your Apple Health data in XML format ([instructions])
2. Download and extract [the latest release] of Bloom Parser for your OS
3. Run Bloom Parser and follow the instructions
4. Use Bloom to [import] the generated CSV file in the Meditation Mind Discord

[Bloom]: https://meditationmind.org/bloom/
[Meditation Mind]: https://discord.gg/meditationmind
[instructions]: https://support.apple.com/guide/iphone/share-your-health-data-iph5ede58c3d/ios#iphe962dcbd2
[the latest release]: https://github.com/meditationmind/bloomparse-gui/releases
[import]: https://meditationmind.org/bloom/#import
